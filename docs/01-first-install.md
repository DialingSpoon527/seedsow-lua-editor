# Start with your existing Lua Editor

This installer guide is for a console where the Seedsow Lua Editor already opens. Begin with [Prepare your computer and editor](02-existing-editor.md), then choose manual entry, a Pi, a Pico, or [Plume USB with a modded Switch 1](https://github.com/RealRobertBrownieJr/seedsow-artemis-plume-installer).

If your editor no longer opens, recover your existing setup before starting this installation. The following guides depend on being able to select slots, edit a Lua file, and run a buffer.
