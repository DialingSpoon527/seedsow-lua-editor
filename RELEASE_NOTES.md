# Seedsow Lua Editor 0.1.0

A standalone Lua editor inside Seedsow Lullaby, with text/hex editing, wired
keyboard input, persistent program slots and recovery copies.

**Vibecoded:** built with AI assistance and hands-on console testing. Expect
rough edges.

## Install first; do the rest later

Download **seedsow-lua-editor-0.1.0.zip** and read its README. First build the
editor save from your compatible backup, restore it on an original Switch
using a save manager, then use Nintendo's individual-save transfer to move it
to Switch 2. The package includes the step-by-step installation guide.

Once the editor and a saved program load after a restart, ordinary editing,
saving and running happen on Switch 2. Keep the game, save and recovery slots
intact, and retain a backup. You can add compatible updates later.

## A Pi is optional

The controller/character grid or a wired USB keyboard is enough to use the
installed editor. If you have a Raspberry Pi, the included Windows app and
Pi bridge provide a convenient way to upload larger files without typing
them on the console. You can set that up whenever you want.

## Download contents

- Console Lua editor and installation-save builder.
- Optional Windows companion and Raspberry Pi controller bridge.
- Guides for installation, manual editing, uploads, later updates and recovery.
- Source and local checks. Python 3.10+ with Tcl/Tk runs the Windows tool.

This source package contains no personal backups or connection credentials.
Installation ZIPs are generated locally from the owner's compatible save.
Supported game build: **Seedsow Lullaby US demo 1.0.0**.

The core editing/upload/save/restart flow has real-console results, including
Switch 2. The new PC/Pi packaging and alongside-editor update still need a
fresh hardware trial. Checksums and a file manifest accompany the download.
